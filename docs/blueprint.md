# **App Name**: Labyrinth Forge

## Core Features:

- Grid Customization: Allow the user to define the dimensions of the maze grid (e.g., 8x8, 16x16).
- Maze Generation: Generate a new maze procedurally using an algorithm (e.g., recursive backtracker, Prim's algorithm).
- Visual Maze Display: Render the maze on screen as a 2D grid of paths and walls.
- Download as SVG: Allow the user to download the generated maze in SVG format.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to evoke a sense of mystery and depth.
- Background color: Light blue-gray (#ECEFF1) for a subtle contrast, making the maze stand out.
- Accent color: Soft orange (#FFAB40) for interactive elements (e.g., generate button).
- Headline font: 'Space Grotesk' sans-serif for headlines and short amounts of text; body font: 'Inter' for any description/explanation of usage
- Use simple line icons for 'generate' and 'download' actions.
- Center the maze display with clear spacing around the grid. Provide the customization settings to the side.
- Subtle fade-in animation upon generating a new maze.
